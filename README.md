# Буквоїд

Вебзастосунок (PWA) для комп'ютера й телефона: **друк наосліп**, **український
правопис** і **англійська** (Elementary та Intermediate). Працює без інтернету,
встановлюється як звичайна програма.

**Відкрити:** https://vitaliylobko.github.io/bukvoid/ (GitHub Pages, гілка `main`).

## Встановлення

- **Комп'ютер** (Chrome або Edge): відкрити посилання → значок «Установити» праворуч
  в адресному рядку. Застосунок відкривається окремим вікном — друкувати зручніше.
- **Android**: меню ⋮ → «Установити застосунок».

## Розділи

| Розділ | Що там |
|---|---|
| **Друк** | курс для української, англійської й російської розкладок: основний ряд → верхній → нижній → і/ї/є/ґ/апостроф → Shift → знаки → цифри → текст. У кожному уроці три вправи (нові клавіші, сполучення, слова); зараховано від 97% точності. Екранна клавіатура з зонами пальців і підсвіткою наступної клавіші, підказка «перемкніть розкладку». Вільне тренування: слабкі клавіші (за статистикою помилок), слова, текст, свій текст |
| **Курси** | підключувані курси: теорія, приклади, тест, друк. Вбудований — «Український правопис» (11 тем за редакцією 2019 року). Нові — з каталогу або з файлу, **⚙ → Курси** |
| **English** | 2 рівні по 12 юнітів: правило, приклади з озвученням, фрази, відео й онлайн-уроки, тест (вибір, пропуск, «виправте помилку», переклад), друк фраз. Фрази юнітів — у колоді інтервального повторення (українською → англійською) |
| **Прогрес** | з'їдено букв, хвилини, найкраща швидкість, 14 днів, пройдені курси, слабкі клавіші |
| **⚙** | режим помилок (зупинка / без зупинки), клавіатура, розмір тексту, тема, курси, синхронізація, резервна копія у файл |

## Як рахується

- **Точність** = правильні натискання / усі натискання.
- **Швидкість** — знаків за хвилину; паузи довші за 2 с не рахуються.
- **Рівність ритму** — наскільки однакові проміжки між натисканнями (100 — ідеально рівно).

## Дані

Усе зберігається в браузері (`localStorage`, ключі `bukvoid:*`). Перенести на інший
пристрій — **⚙ → Зберегти копію** і **Відновити з файлу**.

**⚙ → Підключити Google Диск** — прогрес синхронізується через файл `bukvoid.json` на
вашому Диску (доступ `drive.file`: застосунок бачить лише свої файли, сервера немає).
Злиття без конфліктів: у курсах береться найкращий результат, лічильники друку кожного
пристрою зберігаються окремо й складаються, картки повторення — новіша. «Стерти весь
прогрес» і «Відновити з файлу» замінюють прогрес і на інших пристроях. Налаштування
(тема, режим помилок, розмір тексту) у кожного пристрою свої.

**⚙ → Синхронізація** — через сервер бота [Хобі-плану](https://vitaliylobko.github.io/hobby-planner/),
тим самим ключем доступу (`/key` у Telegram-боті; вставлений у Хобі-плані, Вазі чи Марнотраті на
цьому пристрої — тут уже є). Кожен пристрій пише лише свої частини стану (`/api/records`, `app:
bukvoid`), чужі зливає так само, як із Диска. Диск тоді — щоденна копія. Боту йдуть підсумки днів
(`/api/study`): хвилини, швидкість, точність, пройдені уроки й тести, фрази на повторення — для
вечірнього підсумку й тижня в Telegram, нагадування про повторення і автозарахування заняття
Хобі-плану з позначкою «Зараховувати з Буквоїда».

## Курси

Курс — один файл JSON, без коду. Каталог — `courses/index.json` (id, version, назва, кількість
юнітів, файл). Курси з каталогу й з файлу зберігаються в IndexedDB браузера (`bukvoid-courses`);
курс із файлу — лише на тому пристрої, де його додали. Прогрес —
`courses[id курсу][id юніта] = {best, total, at}` у стані, синхронізується як решта. Тому
**id курсу й юнітів після випуску не змінювати** — інакше прогрес загубиться.

```jsonc
{
  "format": "bukvoid-course", "v": 1,
  "id": "geometry-8",               // латиниця, цифри, дефіс; 2–40 знаків
  "version": 1,                     // підняти при зміні — пристрої оновлять курс з каталогу
  "title": "Геометрія, 8 клас", "subtitle": "…",
  "lang": "uk",                     // мова друку: uk | en
  "author": "…", "source": { "title": "…", "url": "https://…" },
  "units": [{
    "id": "triangle", "title": "Трикутник", "goal": "що вмітиме після теми",
    "theory": [                     // блоки h, p, ul, tip, warn, table
      { "p": "Сума кутів трикутника — **180°**." },
      { "table": [["Кут", "Градуси"], ["A", "60"]] }
    ],
    "examples": ["рядок", { "w": "слово", "note": "пояснення" }],
    "exercises": [
      { "type": "choice", "q": "…", "options": ["…", "…"], "a": 1, "why": "…" },
      { "type": "gap", "q": "Прямий кут — ◻°", "a": ["90"], "why": "…" }
    ],
    "typing": ["речення для друку"],
    "media": [{ "title": "…", "url": "https://…", "note": "…" }]
  }]
}
```

- Розмітка в текстах — лише `**жирний**` і `` `код` ``; HTML показується як текст.
- Вправи: `choice` (`a` — номер правильного варіанта від 0), `gap`, `fix`, `translate`
  (`a` — список правильних відповідей).
- Обмеження: до 200 юнітів, файл до 3 МБ, посилання лише `https://`.

Перевірка — та сама, що в застосунку: `node tools/check-course.mjs курс.json`. Без аргументів —
усі курси каталогу і їхня відповідність `index.json`. Новий курс у каталозі — файл у `courses/`
і рядок в `index.json`; нова версія застосунку для цього не потрібна: каталог service worker
спершу бере з мережі.

## Розробка

Без збирання: HTML, CSS і JS-модулі. Контент — `courses/` і `js/data/` (`en-a2.js`,
`en-b1.js`, `words.js`). При кожному релізі підняти `APP_VERSION` / `APP_BUILD`
у `version.js`. Локально service worker вимкнено, увімкнути — `?sw` в адресі.
