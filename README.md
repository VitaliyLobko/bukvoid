# Буквоїд

Вебзастосунок (PWA) для комп'ютера й телефона: **друк наосліп**, **український
правопис** і **англійська** (Elementary та Intermediate) — курсами, до яких можна додавати нові. Працює без інтернету,
встановлюється як звичайна програма.

**Відкрити:** https://vitaliylobko.github.io/bukvoid/ (GitHub Pages, гілка `main`).

## Встановлення

- **Комп'ютер** (Chrome або Edge): відкрити посилання → значок «Установити» праворуч
  в адресному рядку. Застосунок відкривається окремим вікном — друкувати зручніше.
- **Android**: меню ⋮ → «Установити застосунок».

## Розділи

| Розділ | Що там |
|---|---|
| **Курси** | усе навчання — курсами: «Друк наосліп» для української, англійської й російської розкладок: основний ряд → верхній → нижній → і/ї/є/ґ/апостроф → Shift → знаки → цифри → текст. У кожному уроці три вправи (нові клавіші, сполучення, слова); зараховано від 97% точності. Екранна клавіатура з зонами пальців і підсвіткою наступної клавіші, підказка «перемкніть розкладку». На сторінці курсу друку — «сьогодні» й вільне тренування: слабкі клавіші (за статистикою помилок), слова, текст, свій текст. Далі підключувані курси: теорія, приклади, тест, друк. Вбудовані — «Український правопис» (11 тем за редакцією 2019 року), «English A2 · Elementary» і «English B1 · Intermediate» (по 12 тем: приклади з озвученням, фрази, відео й онлайн-уроки, тест — вибір, пропуск, «виправте помилку», переклад). Фрази тем — у колоді інтервального повторення (українською → англійською), «Повторення фраз» угорі вкладки. Нові курси — з каталогу («Ще в каталозі» внизу вкладки, кнопка «Додати») або з файлу, **⚙ → Курси** |
| **Поточний курс** | кнопка посередині нижньої панелі (на комп’ютері — між «Курси» і «Прогрес»): останній відкритий курс на цьому пристрої |
| **Прогрес** | з'їдено букв, хвилини, найкраща швидкість, 14 днів, пройдені курси, слабкі клавіші |
| **⚙** | режим помилок (зупинка / без зупинки), клавіатура, розмір тексту, тема, курси, синхронізація, резервна копія у файл |

## Як рахується

- **Точність** = правильні натискання / усі натискання.
- **Швидкість** — знаків за хвилину; паузи довші за 2 с не рахуються.
- **Рівність ритму** — наскільки однакові проміжки між натисканнями (100 — ідеально рівно).

## Дані

Усе зберігається в браузері (`localStorage`, ключі `bukvoid:*`). Перенести на інший
пристрій — **⚙ → Зберегти копію** і **Відновити з файлу**.

**⚙ → Підключити Google Диск** — прогрес синхронізується через файл `bukvoid.json` на
вашому Диску (доступ `drive.file`: застосунок бачить лише свої файли, сервера немає).
Злиття без конфліктів: у курсах береться найкращий результат, лічильники друку кожного
пристрою зберігаються окремо й складаються, картки повторення — новіша. «Стерти весь
прогрес» і «Відновити з файлу» замінюють прогрес і на інших пристроях. Налаштування
(тема, режим помилок, розмір тексту) у кожного пристрою свої.

**⚙ → Синхронізація** — через сервер бота [Хобі-плану](https://vitaliylobko.github.io/hobby-planner/),
тим самим ключем доступу (`/key` у Telegram-боті; вставлений у Хобі-плані, Вазі чи Марнотраті на
цьому пристрої — тут уже є). Кожен пристрій пише лише свої частини стану (`/api/records`, `app:
bukvoid`), чужі зливає так само, як із Диска. Диск тоді — щоденна копія. Боту йдуть підсумки днів
(`/api/study`): хвилини, швидкість, точність, пройдені уроки й тести, фрази на повторення — для
вечірнього підсумку й тижня в Telegram, нагадування про повторення і автозарахування заняття
Хобі-плану з позначкою «Зараховувати з Буквоїда».

## Курси

Курс — дані, без коду: один файл JSON, а курс із картинками — **пакет**: `course.json` і папка
`img/` поруч. У каталозі пакет — папка `courses/<id>/`, файлом — архів `.zip` з тим самим (курс
може лежати й в одній папці всередині архіву). Каталог — `courses/index.json` (id, version, назва,
кількість юнітів, `file` або `dir`). Картинки зберігаються разом із курсом — він працює без мережі. Курси з каталогу й з файлу зберігаються в IndexedDB браузера (`bukvoid-courses`);
курс із файлу — лише на тому пристрої, де його додали. Прогрес —
`courses[id курсу][id юніта] = {best, total, at}` у стані, синхронізується як решта. Тому
**id курсу й юнітів після випуску не змінювати** — інакше прогрес загубиться.

```jsonc
{
  "format": "bukvoid-course", "v": 1,
  "id": "geometry-8",               // латиниця, цифри, дефіс; 2–40 знаків
  "version": 1,                     // підняти при зміні — пристрої оновлять курс з каталогу
  "title": "Геометрія, 8 клас", "subtitle": "…",
  "lang": "uk",                     // мова друку: uk | en (en — ще й озвучення прикладів і фраз)
  "pass": 0.8,                      // частка правильних для «пройдено»; без поля — тест без помилок
  "icon": "geometry",               // значок курсу — ключ з js/icons.js (див. нижче); без поля — книжка
  "author": "…", "source": { "title": "…", "url": "https://…" },
  "units": [{
    "id": "triangle", "title": "Трикутник", "topic": "підзаголовок", "goal": "що вмітиме після теми",
    "theory": [                     // блоки h, p, ul, tip, warn, table, img, swatches, contrast
      { "p": "Сума кутів трикутника — **180°**." },
      { "table": [["Кут", "Градуси"], ["A", "60"]] },
      { "img": "img/triangle.svg", "alt": "Трикутник ABC з кутами по 60°", "caption": "підпис" },
      { "swatches": [{ "hex": "#1e88e5", "name": "Основний", "note": "кнопки, посилання" }] },
      { "contrast": [{ "fg": "#ffffff", "bg": "#1e88e5", "text": "Кнопка" }] }
    ],
    "examples": ["рядок", { "w": "слово", "note": "пояснення" }],   // або пари { "en": "…", "uk": "…" }
    "words": [{ "en": "nice to meet you", "uk": "приємно познайомитися", "ex": "Nice to meet you, I'm Alex." }],
    "exercises": [
      { "type": "choice", "q": "…", "options": ["…", "…"], "a": 1, "why": "…" },
      { "type": "gap", "q": "Прямий кут — ◻°", "a": ["90"], "why": "…" }
    ],
    "typing": ["речення для друку"],
    "media": [{ "title": "…", "url": "https://…", "note": "…" }]
  }]
}
```

- Розмітка в текстах — лише `**жирний**` і `` `код` ``; HTML показується як текст.
- Вправи: `choice` (`a` — номер правильного варіанта від 0), `gap`, `fix`, `translate`
  (`a` — список правильних відповідей). Будь-яка вправа може мати картинку над питанням: `img` і `alt`.
- `img` — шлях усередині пакета (`img/назва.svg`, `.png`, `.jpg`, `.webp`, `.gif`), без `..` і
  адрес; `alt` обов'язковий — що на картинці, для тих, хто її не бачить. Картинка до 1 МБ, пакет до
  15 МБ. SVG зі скриптом чи обробником подій не приймається; SVG показується як `data:`, решта — `blob:`.
- `swatches` — палітра до 12 кольорів `{hex, name, note}`; `contrast` — до 8 пар `{fg, bg, text}`:
  застосунок сам рахує контраст за WCAG і пише, що пара дозволяє (AAA від 7:1, AA від 4.5:1, великий
  текст від 3:1). Кольори — лише `#rrggbb`.
- `words` — фрази для колоди повторення: потрапляють туди, щойно тему відкрито.
- `icon` — один із: `book`, `keyboard`, `pen`, `languages`, `palette`, `layout`, `geometry`, `math`,
  `flask`, `leaf`, `landmark`, `globe`, `code`, `heart`, `idea`, `music`, `chart`. Малюнок — наш
  (`js/icons.js`): довільний SVG з курсу в сторінку не потрапляє.
- Друк наосліп — теж курси на вкладці «Курси» (`druk-uk`, `druk-en`, `druk-ru`), але вбудовані: уроки
  будуються з розкладки, файлу курсу немає. У ⚙ → «Курси» їх лише показують чи ховають
  (`bukvoid:courses-off`, російську типово сховано); вкладки «Друк» немає (з 0.1.8): старий `#druk` веде в курс друку останньої мови.
- Обмеження: до 200 юнітів, файл JSON до 3 МБ, посилання лише `https://`.
- Вбудовані курси (`builtIn` в `index.json`) ставляться самі; видалений на пристрої курс сам не
  повертається (`bukvoid:courses-removed`), його можна додати з каталогу.
- Старі поля стану `spelling` і `english` (до 0.1.5) зливаються в курси `uk-pravopys`, `en-a2`,
  `en-b1`; на Диск і сервер вони й далі їдуть копією — для пристроїв на старих версіях. Картки
  англійської зберігають старий ключ `юніт:фраза`, картки інших курсів — `курс/юніт:фраза`.

Перевірка — та сама, що в застосунку: `node tools/check-course.mjs курс.json | курс.zip | папка`.
Без аргументів — усі курси каталогу і їхня відповідність `index.json`. Новий курс у каталозі — файл
у `courses/` (або папка пакета) і рядок в `index.json`; нова версія застосунку для цього не потрібна: каталог service worker
спершу бере з мережі.

## Розробка

Без збирання: HTML, CSS і JS-модулі. Контент — `courses/` і `js/data/words.js` (слова для друку). При кожному релізі підняти `APP_VERSION` / `APP_BUILD`
у `version.js`. Локально service worker вимкнено, увімкнути — `?sw` в адресі.
